\# Kindred – AI-Driven Smart Donation Management System



AI-Driven Smart Donation Management System for Intelligent Resource Allocation and Community Support.



Kindred is an AI-powered donation management platform designed to connect donors and NGOs and improve the process of donation classification, resource allocation, intelligent matching, and coordination.



\## Key Features



\- Donor and NGO registration and authentication

\- AI-based donation classification

\- Intelligent donor–NGO matching

\- NGO demand and priority management

\- Quantity, proximity, and priority-based matching

\- Match explanations and recommendations

\- Donation status tracking

\- Real-time notifications

\- Pickup and delivery coordination

\- Progressive Web App (PWA) support

\- Multilingual interface

\- Responsive and accessible UI



\## Technology Stack
